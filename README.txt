GAMMA Coop 0.95 - установщик S.T.A.L.K.E.R. G.A.M.M.A. + кооп xrRazom (ШАГ 1 из 2)

Запуск: двойной клик по "GAMMA Coop.bat".

Что делает сейчас (шаг 1):
- просит права администратора (окно UAC - нажми "Да");
- открывает окно установщика (в Windows Terminal, если он есть);
- показывает анимированную заставку и выбор папки установки ([P] - сменить);
- переключает моды клавишами 1-4;
- проверяет: права, запущен ли zapret/GoodbyeDPI/ByeDPI, место на диске,
  тип диска (SSD/HDD/внешний), скорость GitHub и зеркала Anomaly, нужен ли VPN;
- запрещает ПК засыпать, пока окно открыто;
- пишет журнал в installer\logs\.

Саму игру этот шаг НЕ скачивает и НЕ ставит - это будет на шаге 2.
Клавиши: Enter - начать, P - папка (в окне папки Ctrl+V или Shift+Insert вставляет путь из буфера; Ctrl+V на главном экране сразу открывает окно с вставленным путём), 1-4 - моды, R - проверить снова, Esc или Q - выход.
Проверка скорости немного скачивает данные (до 8 секунд с каждого источника).
Окно должно быть не меньше 100x35 символов.

ШАГ 2 (установка Anomaly и GAMMA):
- Enter на стартовом экране -> согласие (исключения Defender, длинные пути) -> установка.
- Установщик сам скачивает программу stalker-gamma-cli (GPL-3.0, с GitHub, не входит в архив).
- Клавиши: P - пауза/продолжить, L - последние строки лога, Esc - остановить (потом Enter продолжит с места).
- Если ModDB просит подождать - таймер 65 минут, потом продолжит сам (Enter - попробовать сразу).
- Проверка без установки: gamma_coop.ps1 -Headless -Simulate -Frames 120 (кадры в logs\frames_install.txt);
  gamma_coop.ps1 -Simulate - то же в окне, ускоренно.
