## Что это

Поставить G.A.M.M.A. и кооп вручную — это час чтения гайдов, десятки гигабайт, ModDB-лимиты и
«у меня не так, как у тебя». **GAMMA Coop** делает всё сам и следит, чтобы у всех в компании
стояла **одинаковая** сборка — иначе кооп не работает.

```
   ╭─ ЧТО ДЕЛАЕМ ───────────────────────────────────────────────────────────────────────────────╮
   │ ▸ [1] Установить GAMMA с нуля                                                              │
   │       новая установка Anomaly, GAMMA и кооп в пустую папку                                 │
   │   [2] Загрузить сборку — обновить игру как у друга/хоста                                   │
   │       найду файл сборки сам (Загрузки, LocalSend, рабочий стол) и покажу, что изменится    │
   │   [3] Сохранить сборку — сделать файл для друзей                                           │
   │       один файл со всеми твоими модами сверх стандартной GAMMA — отправь его друзьям       │
   │   [4] Починить кооп                                                                        │
   │       поставить кооп заново из последней сборки, если что-то сломалось                     │
   ╰────────────────────────────────────────────────────────────────────────────────────────────╯
```

## Возможности

| | |
|---|---|
| 📦 **Установка с нуля** | Сам скачивает Anomaly и G.A.M.M.A., проверяет файлы, ставит кооп xrRazom и озвучку |
| 🔁 **Синхронизация сборки** | Хост жмёт «Сохранить сборку» → отправляет файл (LocalSend, Telegram…) → друг жмёт «Загрузить» — и у него всё 1:1 |
| 🔍 **Показывает разницу** | Перед заменой видно, какие моды добавятся, обновятся или выключатся |
| ⌨️ **Бинды по желанию** | Можно забрать раскладку клавиш хоста — или оставить свою (по умолчанию своя) |
| 🛟 **Резервные копии** | Всё, что меняется, сначала уходит в бэкап; если что-то пошло не так — откат |
| ⚡ **Продолжение после обрыва** | Выключили свет, вылетел интернет — при следующем запуске продолжит с того же места |
| 🛡️ **Защита от дурака** | Не даст поставить в системные папки, «Документы», «Загрузки» и т. п. Ставит только в пустую папку |
| 🚀 **Лаунчер** | Сам замечает новую сборку в «Загрузках» и предлагает её поставить |
| 🩺 **Проверка целостности** | Сверяет все моды с хостом и находит пропавшие или битые файлы; хост одной кнопкой собирает архив для починки |
| ↩️ **Безопасное обновление базы** | [U] докачивает только разницу, а при обрыве возвращает моды как были |
| 📝 **Журнал** | Всё пишется в лог — легко понять, что случилось |

## Как пользоваться

### Хост (тот, у кого «правильная» сборка)
1. Скачай установщик: **Code → Download ZIP** (или со страницы [Releases](../../releases)) и распакуй.
2. Запусти **`GAMMA Coop.bat`** → **[3] Сохранить сборку**.
3. Отправь получившийся `GAMMA_Coop_build_….zip` друзьям.

### Друг
1. Скачай установщик **отсюда же** и распакуй.
2. Положи присланный файл сборки в «Загрузки».
3. Запусти **`GAMMA Coop.bat`**:
   - GAMMA ещё нет → **[1] Установить с нуля** (нужна пустая папка, ~150 ГБ и время);
   - GAMMA уже стоит → **[2] Загрузить сборку**.

> Перед [2], [3] и [4] закрой игру и Mod Organizer 2 — установщик проверит это сам.

## Требования

- Windows 10/11, права администратора (окно UAC — «Да»)
- Диск NTFS, ~150 ГБ свободно для установки с нуля, путь латиницей и короче 60 символов
- Окно терминала не меньше 100×35 символов
