01Запуск

Запускать игру нужно только через ярлык «GAMMA Coop» на рабочем столе.

ВажноНе запускать от имени администратора — иначе Discord не покажет игру.
  1. Откроется Mod Organizer 2.
  2. Сверху справа выбрать Anomaly (DX11) и нажать Run.
  3. Моды в списке слева не трогать.

02Первый запуск

  1. Открыть Настройки → xrRazom Co-op, вкладка Player, и задать имя игрока.
  2. Назначить клавиши метки и чата: Настройки → Управление → Клавиши → xrRazom Co-op (в самом низу списка).
ВажноИмя = профиль у хоста. Если поменять имя, хост увидит нового игрока.
ВажноБез назначенной клавиши метка и чат не работают.

03Как играть вместе

Основной способ — по IP через Radmin VPN. Игра выбирает способ при запуске по тому, открыт ли Steam, поэтому для этого способа Steam нужно закрыть.

Через Radmin VPN (основной способ)

  1. Каждый игрок устанавливает Radmin VPN (бесплатно): radmin-vpn.com.
  2. Хост создаёт сеть: Сеть → Создать сеть, задаёт имя и пароль и сообщает их друзьям. Остальные: Сеть → Присоединиться к сети.
  3. IP хоста — тот, что показан в Radmin VPN рядом с именем хоста (начинается с 26.).
  4. Все закрывают Steam перед запуском игры.
  5. Хост: Настройки → xrRazom Co-op → Hosting, включить только Host session on game start, затем начать новую игру или загрузить сохранение.
  6. Остальные: главное меню → Connect to Session → IP хоста из Radmin VPN → Join.
ВажноЕсли не подключается: при первом запуске Windows может спросить про брандмауэр — разрешите игре доступ (для частных и общественных сетей).

Без Radmin VPN можно играть по обычному IP, если у хоста открыт порт (настройка Hosting → LAN port).

Через Steam (если у всех есть Зов Припяти в Steam)

ВажноУ всех открыт Steam до запуска игры, и у КАЖДОГО на аккаунте есть S.T.A.L.K.E.R.: Call of Pripyat (Зов Припяти).
  • Хост: Настройки → xrRazom Co-op → Hosting, включить Host session on game start и Host via Steam ID, затем новая игра или загрузка.
  • Остальные: в главном меню открыть оверлей Steam (Shift+Tab) → друг → Присоединиться.

После подключения

  • После запуска хост увидит уведомление о старте сервера.
  • Новый игрок выбирает стартовое снаряжение и жмёт Start.
  • Играть можно до 5 человек.

04Правила, чтобы не ломалось

  1. У всех одна и та же сборка — GAMMA Coop 0.95. Иначе подключение отклонят. В логе строка [xrRazom] cfg-diff покажет, какой файл не совпал.
  2. Хост сохраняется перед выходом.
  3. Сохраняйтесь чаще — бывают вылеты при сохранении, загрузке и переходе между локациями.
  4. Не загружать автосейв, сделанный у подключившегося игрока.
  5. Правила сессии (огонь по своим, спасение раненых и т. п.) задаёт хост.

05Если пропал кооп

После обновления GAMMA через её лаунчер или после переустановки кооп слетает — возвращаются обычные exe.

  1. Запустить установщик GAMMA Coop.
  2. Нажать [K] «Починить кооп».
ВажноНе обновлять GAMMA без хоста — версии должны совпадать.

06Частые проблемы

Discord не показывает игру
Проверьте: Discord запущен, игра открыта через ярлык и не от имени администратора.
Не пускает к хосту
Проверьте: в Radmin VPN хост онлайн (зелёная точка), у всех закрыт Steam, у всех одна и та же сборка (при необходимости — «Починить кооп»). Если играете через Steam — у всех открыт Steam и есть Зов Припяти.
